## собственный проект

**Тема проекта:** каталог игр

**Главный класс:** Game

`Почему этот объект нужен программе:`
класс Game описывает одну игру в каталоге и хранит все её ключевые характеристики в одном месте.

`Какие данные хранит объект:`

- Title — название игры
- Genre — жанр
- ReleaseYear — год выхода
- Rating — рейтинг

`Какие значения задаются через конструктор:`
Title, Genre, ReleaseYear

Rating = 0.0 — у новой игры в каталоге ещё нет рейтинга, он появляется позже
Rating = 0.0, потому что у только что добавленной в каталог игры ещё нет оценок

# ЛАБ 2

**метод 1:** UpdateRating

- записывает новый рейтинг игры, если он в диапазоне от 0 до 10;
  иное значение отклоняется, состояние не меняется

**метод 2:** AddPlayHours

- прибавляет наигранные часы, если передано положительное число;
  отрицательное и нулевое значение отклоняется.

**метод 3:** IsHighlyRated

- возвращает true, если рейтинг игры 9.0 и выше, иначе false

1. при yaroslav.TakeDamage(25); число 25 попадает в параметр damage, а метод работает с полями именно того объекта у которого вызван, то есть со здоровьем ярика. артём и настя — отдельные объекты со своим состоянием, их вызов не касается.
2. return; в TakeDamage — досрочный выход из void-метода без всякого значения: «действие отклонено, делать больше нечего». return Health > 0; в IsAlive — сначала вычисляет выражение по текущему здоровью, затем возвращает результат (true или false) в место вызова.
