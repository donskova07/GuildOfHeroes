## собственный проект

**Тема проекта:** каталог игр

**Главный класс:** Game

`Почему этот объект нужен программе:`
класс Game описывает одну игру в каталоге и хранит все её ключевые характеристики в одном месте.

`Какие данные хранит объект:`

- Title — название игры
- Genre — жанр
- ReleaseYear — год выхода
- Rating — рейтинг

`Какие значения задаются через конструктор:`
Title, Genre, ReleaseYear 

Rating = 0.0 — у новой игры в каталоге ещё нет рейтинга, он появляется позже
Rating = 0.0, потому что у только что добавленной в каталог игры ещё нет оценок
